# Termfetch showcase

Made a card you like? Add it here so other developers can discover new themes,
layouts, and configuration ideas.

## How to contribute

1. Commit the generated SVG and its configuration to your GitHub profile repository.
2. Add one row to the table below with a direct link to your profile repository.
3. Open a pull request. Do not add private information or images you do not have permission to share.

| Developer | Card | Theme | Configuration |
| --- | --- | --- | --- |
| [@saivarun1410](https://github.com/saivarun1410) | [View card](https://github.com/saivarun1410/saivarun1410/blob/main/card-light.svg) | GitHub Light | [Profile repository](https://github.com/saivarun1410/saivarun1410) |

When sharing elsewhere, an optional attribution line is:

```markdown
<sub>Generated with [termfetch](https://github.com/saivarun1410/termfetch).</sub>
```
