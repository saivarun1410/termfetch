# Changelog

All notable changes to Termfetch are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## 0.2.0 - 2026-08-15

### Added

- `termfetch init` for generating a portable starter configuration.
- Default `termfetch.json` input and `termfetch.svg` output paths for a shorter first-run flow.
- `termfetch --version` output.
- Reusable scheduled-refresh workflow and theme gallery.
- CI coverage for Python 3.14 and current GitHub Actions runtimes.

### Changed

- The README now leads with the published PyPI installation instead of cloning the source.

## 0.1.0 - 2026-08-08

### Added

- Initial PyPI and GitHub release.
- Portrait and logo rendering with ASCII, blocks, solid cells, and half-blocks.
- GitHub profile statistics and configurable template fields.
- Six built-in themes and per-colour overrides.
- Self-contained SVG generation with optional scheduled refreshes.
