# Changelog

All notable changes to termfetch are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-08

### Added

- Generate self-contained GitHub profile cards as SVG.
- Render photos as coloured ASCII, block, solid, or half-block terminal art.
- Fetch public profile, repository, star, fork, follower, and language statistics.
- Configure themes, colours, layout, crop, wrapping, and template fields with JSON.
- Refresh cards automatically with a scheduled GitHub Actions workflow.
- Support Python 3.10 through 3.13.
